# Code of Conduct

Ujima Agents is built for collaboration, learning, and shared momentum.

## Our Standards

We expect contributors and maintainers to:

- be respectful and direct without being hostile
- give feedback on the work, not the person
- welcome new contributors and questions
- keep discussions focused on the project
- respect privacy, security boundaries, and workspace constraints

## Unacceptable Behavior

The following are not acceptable in this project:

- harassment, threats, or discriminatory language
- personal attacks or public shaming
- spam, trolling, or deliberate disruption
- leaking secrets, private data, or access tokens
- attempts to bypass security or workspace boundaries

## Enforcement

Maintainers may remove, edit, or close content that violates this code of conduct. Repeated or severe violations may result in loss of contributor privileges.

## Reporting

If you need to report a conduct issue, contact the maintainers privately through the GitHub repository security or organization contact path before using public issues.

## Scope

This code of conduct applies to repository issues, pull requests, discussions, and any project spaces linked from this repository.
